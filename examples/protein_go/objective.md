Evolve a Python function that predicts Gene Ontology Molecular Function (GO-MFO) terms for a protein sequence. The function receives the amino acid sequence and nine tool callables (`blast`, `uniprot`, `go_ancestors`, `sequence_features`, `llm`, `embed`, `score`, `esm_embed`, `esm_nearest`) and returns a dict mapping GO term IDs to confidence scores in [0, 1].
