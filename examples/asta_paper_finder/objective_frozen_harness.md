Tune the settings of a fixed PaperFindingBench agent. The agent's code is frozen for this run: given a natural-language literature-search query, it returns a list of Semantic Scholar corpus_ids, scored by adjusted micro-F1 against the query's hidden gold. You do not write or change agent code. You produce one file, `${CONFIG_FILE}`, which sets the frozen agent's model for each of its model slots, the reasoning effort of each, and its numeric and boolean constants (see "Config-only evolution" in Domain Background in CLAUDE.md).
