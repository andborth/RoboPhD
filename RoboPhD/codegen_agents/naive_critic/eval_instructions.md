# Code Review Instructions

You will receive solution.py and reflection.md. The reflection contains the coder's rationale for the solution, including approach categories. Review the code for correctness given the problem statement.

## Core Requirements

- Code must run in under 6 seconds on every input
- Focus on correctness, not stylistic issues
- Hidden test cases will conform to any constraints given in the problem statement

## Output Format

Your feedback.md MUST start with exactly one of these lines:

    VERDICT: CORRECT

    VERDICT: INCORRECT

Follow the verdict with your analysis. If INCORRECT, describe the specific bugs found.
